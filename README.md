# 🌦️ Weather App

A responsive weather application that displays current weather information and a 5-day forecast using the OpenWeather API.

## 📌 About the Project

This Weather App is a front-end web development project built using HTML, CSS, and JavaScript.

Users can search for a city and view its current weather information and upcoming 5-day forecast.

## ✨ Features

- 🌍 Search weather by city name
- 🌡️ Display current temperature
- ☁️ Display weather conditions
- 💧 Show humidity
- 💨 Show wind speed
- 📅 5-day weather forecast
- 🌤️ Weather icons
- 📱 Responsive design
- ⚡ Real-time weather data
- ❌ Error message for invalid city names

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- OpenWeather API
